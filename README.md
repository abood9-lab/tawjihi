# 📚 TawjihiGuide - الدليل الشامل لالتوجيهي

منصة تعليمية متكاملة للطلاب والمعلمين مع نظام نقاط وشارات وذكاء اصطناعي.

## 🚀 كيفية البدء

### المتطلبات
- Node.js v16 أو أعلى
- npm أو yarn

### التثبيت والتشغيل

#### 1️⃣ تثبيت المكتبات
```bash
npm install
```

#### 2️⃣ تشغيل سيرفر GROQ API (في نافذة terminal منفصلة)
```bash
npm start
```

سيظهر:
```
┌─────────────────────────────────────┐
│  🚀 GROQ API Server Running         │
│  Server: http://localhost:3001      │
│  Endpoint: /api/chat                │
│  Health: /api/health                │
└─────────────────────────────────────┘
```

#### 3️⃣ تشغيل خادم الويب (في نافذة terminal أخرى)
```bash
# باستخدام Live Server أو
npx --yes serve . -l 5500

# أو استخدم VS Code Live Server Extension
```

### 📱 الوصول إلى التطبيق
- افتح المتصفح على: `http://localhost:5500`
- اختبر الـ AI Chat من Dashboard

## 🤖 نظام الـ AI Chatbot

### كيفية العمل:
1. المستخدم يكتب سؤال في Dashboard
2. السؤال يُرسل إلى `server.js` على المنفذ 3001
3. السيرفر يعيد إرسال السؤال إلى GROQ API
4. الرد يعود إلى المتصفح

### المميزات:
- ✅ لا توجد مشاكل CORS
- ✅ مفتاح API آمن على السيرفر
- ✅ fallback ذكي عند انقطاع الاتصال
- ✅ دعم سجل المحادثة

## 🔐 الأمان

### المتغيرات الحساسة
جميع المفاتيح تُخزن في ملف `.env`:
```env
GROQ_API_KEY=...
FIREBASE_API_KEY=...
YOUTUBE_API_KEY=...
```

⚠️ **لا تشارك ملف `.env` على GitHub!**

### قواعد Firestore
- 🔒 المستخدمون لا يستطيعون قراءة بيانات الآخرين
- 🔒 المعلمون فقط يمكنهم إضافة أسئلة
- 🔒 المسؤولون فقط يمكنهم إدارة قائمة المعلمين

## 🛠️ استكشاف الأخطاء

### المشكلة: "Cannot connect to server"
**الحل**: تأكد من تشغيل `npm start` في terminal منفصلة

### المشكلة: "GROQ API Error"
**الحل**: تحقق من مفتاح API في ملف `.env`

### المشكلة: "Firebase auth error"
**الحل**: تأكد من إعدادات Firebase في `config.js`
